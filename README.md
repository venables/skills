## Skills

| Skill                                                                                           | Description                                                                                                                                                                                       |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [pr-comment-handler](./skills/pr-comment-handler)                                               | Read every open review comment on a PR, classify each as fix / push-back / defer-to-Linear, drive the work, then post the right reply on each thread (including `Fixed in <sha>` replies on push) |
| [optimize-agents-md](https://github.com/catena-labs/skills/tree/main/skills/optimize-agents-md) | Optimize your AGENTS.md (and CLAUDE.md) files according to best practices. Works with monorepos, too                                                                                              |
| [panel-review](https://github.com/catena-labs/skills/tree/main/skills/panel-review)             | Fan a code review out to multiple local CLI agents (codex, claude, opencode, gemini) in parallel and amalgamate their findings                                                                    |

Most of these skills now live in [catena-labs/skills](https://github.com/catena-labs/skills); `pr-comment-handler` is being developed here on the `pr-comment-handler` branch.
